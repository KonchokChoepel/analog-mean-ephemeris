# Limitations (read before citing)

1. **Mean positions, not real positions.** The calendars follow regular-pace cycles. The true planets differ from them by an *orb*, printed on each Master page.
2. **The epoch is not independently verified.** Orbital elements are Standish (JPL, valid 1800–2050), because the build environment had no access to DE440.
3. **Day-boundary mismatch.** Whole-day year lengths mean about 14.7% of year starts fall in a different calendar day from the true event.
4. **Moon calendar signs are ordinal.** The Moon's 12 lunations drift against the zodiac by about 11° a year.
5. **Month lengths.** Real-apse months are rounded to whole days; changes are listed in the Month-Length Tables.
6. **Redundancy.** Some pair calendars add little beyond the slower planet's own calendar.
7. **Upkeep.** About 49 cycle rollovers a year across the set.
8. **No claim about astrology.** This repository is the timekeeping instrument only; it makes no empirical claim.
